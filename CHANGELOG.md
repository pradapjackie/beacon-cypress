# Changelog

## 0.3.0

- A Cypress run writes the same Beacon report as beacon-reporter: dashboard cards, compare, timeline, flaky scores, trends, requirements, and the shared report commands.
- `owner:`, `severity:`, `requirement:`, `budget:`, and `issue:` written in a title or tag become report annotations.
- `watch: true` refreshes the report after each spec.

## 0.2.1

- A project's `onAfterScreenshot` hook still runs when it is registered before `installBeaconCollector()`, and a hook registered after it no longer turns off named screenshots.
- Trend history uses the Cypress run start, the same time as the report header.
- The report HTML does not request Google Fonts.
- A screenshot taken in `after()` with `{ log: false }` is included.
- `outputFolder: '.'` leaves an existing `index.html` and files in `attachments/` that this report did not write.
- `beacon-cypress open` reports a missing folder, and a bad `--port`, without a stack trace.

## 0.2.0

- The HTML report is generated by this package. It does not depend on Playwright or `beacon-reporter`.
- `toBeaconFixture` was removed. Use `toCypressReport`.
- Open a report with `npx beacon-cypress open beacon-report`.
